# AI Appointment Booking System

An AI-powered Appointment Booking System built with n8n, OpenAI, Google Calendar, Gmail, and workflow automation to automate appointment scheduling and customer communication.

## Project Overview

This project demonstrates a practical appointment booking automation designed for real-world businesses.

The workflow receives appointment requests, processes customer information through n8n, uses intelligent logic to handle booking data, integrates with Google Calendar for appointment scheduling, and can automatically send confirmation emails through Gmail.

## Key Features

- Automated appointment booking
- Google Calendar integration
- OpenAI-powered data processing
- Customer information handling
- Appointment date and time processing
- Automated calendar event creation
- Gmail confirmation emails
- Conditional workflow logic
- Automated booking notifications
- Scalable n8n workflow architecture
